# Stabilization Round Records

This folder is for per-round stabilization experiment records.

Use this folder for:

- Experiment result reports
- Blocked run reports
- Round-specific diagnosis
- Round-specific follow-up notes

Do not put evergreen operating rules here.

Required operating guides live in:

```text
docs/operating_guides/
```

Before starting or continuing any stabilization round, read:

```text
docs/operating_guides/00_agent_workflow_rules.md
docs/operating_guides/01_remote_mac_windows_stabilization_workflow.md
docs/operating_guides/02_integrated_subagent_remote_stabilization_workflow.md
```
